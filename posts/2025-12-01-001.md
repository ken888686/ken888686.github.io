# Next.js 學習筆記

最近開始深入研究 Next.js，特別是 App Router 架構。作為一個習慣 **C# 強型別與後端邏輯**的開發者，Next.js 的 Server Components 讓我有種似曾相識的感覺，就像是在寫 ASP.NET 的 Razor Pages，但更加靈活且前端整合更緊密。

## Server Components 的魅力

能夠在 Component 層級直接存取資料庫（當然要注意安全邊界），大大幅減少了 API endpoints 的 boilerplate code。這對於習慣後端思維的我來說，是一個非常直觀的開發模式。

## 為什麼選擇 Next.js？

- **簡化架構**：不再需要為了讀取資料而特地寫一個 API，可以直接在 Server Component 中 fetch data。
- **效能優化**：自動的 Code Splitting 和 Image Optimization。
- **開發體驗**：TypeScript 支援非常完善。
